# To-Do List

Hi, I'm Haider Sultan, an Electrical Engineering student currently learning Python.

I built this To-Do List as another small project to practice working with lists, functions, loops, conditions, and user input.

The idea is simple: the user can add tasks, view them, remove individual tasks, or clear the entire list.

## What the Program Does

The program allows the user to:

* Add tasks
* View all tasks
* Remove a specific task
* Clear all tasks
* Exit the program

The tasks are stored in a Python list while the program is running.

## Python Concepts I Practiced

This project helped me practice:

* Lists
* Functions
* `while` loops
* `for` loops
* `if / elif / else`
* User input
* `enumerate()`
* List methods such as `append()`, `pop()`, and `clear()`
* Type conversion
* Basic error handling with `try / except`

## Example

When the program starts, it shows a menu:

```text
To-Do List
--------------------
1. Add Task
2. View Tasks
3. Remove Task
4. Clear All Tasks
5. Exit

Enter your choice:
```

After adding a few tasks, the list might look like:

```text
Your Tasks
--------------------
1. Study Python
2. Complete homework
3. Practice programming
```

The user can then choose a task to remove or clear the entire list.

## How to Run It

This project uses only Python's built-in features, so no external packages are required.

Check that Python is installed:

```bash
python --version
```

Then run:

```bash
python to_do_list.py
```
