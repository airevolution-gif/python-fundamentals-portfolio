# Python Quiz Game

Hi, I'm Haider Sultan, an Electrical Engineering student currently learning Python.

I built this quiz game to practice some of the Python concepts I've been learning. I wanted to make something interactive where the user has to answer questions and receive a score at the end.

The questions in this project are focused on basic Python knowledge.

## What the Program Does

The quiz:

* Displays multiple-choice questions
* Accepts answers from the user
* Checks whether the answers are correct
* Keeps track of the score
* Calculates the final percentage
* Allows the user to play again

## Python Concepts I Practiced

This project helped me practice:

* Lists
* Dictionaries
* Functions
* `for` loops
* `while` loops
* Conditions
* User input
* String methods
* `enumerate()`
* Basic calculations
* Input validation

## Example

```text
Question 1
What is the correct file extension for a Python file?

A. .java
B. .py
C. .html
D. .cpp

Your answer: B
Correct!
```

At the end, the program displays the score:

```text
Quiz Finished
--------------------
Your score: 4/5
Percentage: 80.0%
Great job!
```

## How to Run It

No external packages are required.

Run the program with:

```bash
python quiz_game.py
```
