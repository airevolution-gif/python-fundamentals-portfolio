# Expense Tracker

Hi, I'm Haider Sultan, an Electrical Engineering student currently learning Python.

I built this Expense Tracker to practice working with lists, dictionaries, functions, loops, and basic calculations.

The program lets the user record expenses and keep track of how much money has been spent.

## What the Program Does

The Expense Tracker can:

* Add expenses
* View recorded expenses
* Calculate total expenses
* Calculate spending by category
* Delete an expense
* Handle invalid input

Each expense contains a description, amount, and category.

## How to Run It

No external packages are required.

Run the program with:

```bash
python expense_tracker.py
```
