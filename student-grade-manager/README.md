# Student Grade Manager

Hi, I'm Haider Sultan, an Electrical Engineering student currently learning Python.

I built this Student Grade Manager as my second Python project. I wanted to practice working with lists, dictionaries, loops, functions, and conditions by putting them together in a small program.

The program allows the user to enter students and their grades, and then calculates their average and assigns a final letter grade.

## What the Program Does

The program allows you to:

* Enter multiple students
* Enter three grades for each student
* Store student information
* Calculate the average grade
* Assign a letter grade based on the average
* Display the results for all students
* Handle invalid input

## How It Works

When the program starts, it asks for a student's name and then asks for three grades.

The grades are stored in a list, while the student's name and grades are stored together in a dictionary.

After entering all the students, the program calculates each student's average and uses that average to determine the final letter grade.

For example:

```text
Student: Ali
Grades: [80.0, 90.0, 85.0]
Average: 85.00
Final Grade: B
```

## How to Run It

This project does not require any external Python packages.

Make sure Python is installed on your computer:

```bash
python --version
```

Then run the program:

```bash
python student_grade_manager.py
```
