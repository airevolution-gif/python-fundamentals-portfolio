# 🧮 Smart Calculator Pro

This is one of the first Python projects I built while learning Python.

I'm Haider Sultan, an Electrical Engineering student, and I've been spending the last few months learning Python by actually writing programs and building small projects.

I wanted to start with something simple but useful, so I built this command-line calculator and kept adding features as I learned new Python concepts.

## What Can It Do?

The calculator currently supports:

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Modulus
- Square root
- Factorial
- Basic input validation
- Error handling

It also has a simple colored interface and a larger text-based title to make the terminal experience a little nicer.

## What I Practiced

While building this project, I practiced:

- Variables and data types
- `if`, `elif`, and `else`
- `while` loops
- Functions
- User input
- Type conversion
- Error handling with `try` and `except`
- Importing Python modules

## Libraries

I used a few external packages to make the terminal interface better:

- Colorama
- PyFiglet
- Tabulate

You can find them in `requirements.txt`.
