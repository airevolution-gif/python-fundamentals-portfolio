## Running the Projects

All of the projects in this section use Python's standard features.

No external Python packages are required.

First, check that Python is installed:

```bash
python --version
```

Then open the project folder you want to run and use Python to start the program.

For example:

```bash
python calculator.py
```

The exact filename can be found inside each project folder.
