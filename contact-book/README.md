# Contact Book

Hi, I'm Haider Sultan, an Electrical Engineering student currently learning Python.

I built this Contact Book as my third Python project. I wanted to practice working with dictionaries, functions, loops, conditions, and user input by creating something that feels like a small real-world application.

The program lets the user add, view, search, update, and delete contacts.

## What the Program Does

The Contact Book can:

* Add a new contact
* View all saved contacts
* Search for a contact
* Update contact information
* Delete a contact
* Handle invalid menu choices

Each contact contains a name, phone number, and email address.

## Python Concepts I Practiced

While building this project, I practiced:

* `while` loops

## Example

The program starts with a simple menu:

```text
Contact Book
--------------------
1. Add Contact
2. View Contacts
3. Search Contact
4. Update Contact
5. Delete Contact
6. Exit

Enter your choice:
```

For example, after adding a contact:

```text
Name: Ali
Phone: 03001234567
Email: ali@example.com
```

The contact can later be searched, updated, or deleted.

## How to Run It

This project uses only standard Python features, so no external packages are required.

Check that Python is installed:

```bash
python --version
```

Then run the program:

```bash
python contact_book.py
```
