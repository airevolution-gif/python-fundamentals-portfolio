# Personal Diary

Hi, I'm Haider Sultan, an Electrical Engineering student currently learning Python.

I built this Personal Diary project to practice one of the Python topics I wanted to understand better: working with files.

The program allows the user to write diary entries and save them to a text file. The entries can then be viewed or searched later.

## What the Program Does

The diary can:

* Add a new entry
* Save entries to a text file
* View saved entries
* Search entries using a keyword
* Delete all entries
* Handle cases where the diary file does not exist

## Python Concepts I Practiced

This project helped me practice:

* File handling
* Reading files
* Writing files

* `with open()`

## Example

The program starts with:

```text
Personal Diary
--------------------
1. Add Entry
2. View Entries
3. Search Entries
4. Delete All Entries
5. Exit

Enter your choice:
```

After adding entries, they can be displayed like this:

```text
Diary Entries
--------------------
1. Started learning Python today.
2. Practiced functions and loops.
3. Built a small Python project.
```

## How to Run It

No external packages are required.

Run the program with:

```bash
python personal_diary.py
```

The program will create a `diary.txt` file when the first entry is saved.
